# 🌟Spring Boot Demo Project

Spring Boot와 JPA 학습 프로젝트

## ✏️학습 내용

- REST API 구현
- Controller, Service, DAO 계층 분리
- 생성자 주입을 이용한 의존성 주입
- Spring Data JPA와 MariaDB 연동
- Swagger를 이용한 API 테스트

## ⚙️기술 스택

- Java 17
- Spring Boot 4.1.0
- Spring Data JPA
- MariaDB
- Maven
- Swagger

## ✨주요 기능

- 상품 등록
- 상품 단건 조회
